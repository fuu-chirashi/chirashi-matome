# チラシまとめ

個人用の静的Webアプリです。GitHub Pagesに置くと、スマホのブラウザから使えます。

## 使い方

1. 今ほしい物と希望価格を登録する
2. よく見るスーパーのチラシURLを登録する
3. チラシを見て、お買い得やなと思った商品を購入予定に入れる
4. 2週間カレンダーで、日付ごと・スーパーごとに買う候補を見る
5. 買い終わったほしい物はチェックしてリストから消す

## スマホ用メモ

- データはスマホのブラウザ内に保存されます。
- ときどき「バックアップを書き出す」でJSONを保存してください。
- 別のスマホやブラウザで使う時は「バックアップを読み込む」で復元できます。

## GitHub Pages

このフォルダの中身をGitHubリポジトリに置き、GitHub Pagesで公開します。

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

公開されたURLをスマホで開き、共有メニューからホーム画面に追加するとアプリっぽく使えます。
